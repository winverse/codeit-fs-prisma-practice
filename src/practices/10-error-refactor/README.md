# 오류와 ID 검증

## 문제와 시작 상태

누적 프로젝트의 여러 route와 파일을 그대로 복제하지 않고, 같은 에러 처리 규칙을 `src/errors.js`의 축소된 독립 유틸리티로 확인합니다. 상태 코드를 가진 커스텀 에러, 양의 정수 ID 검증 미들웨어, 찾을 수 없는 경로를 전달하는 미들웨어, 중앙 에러 핸들러를 구현합니다. ID 검증 미들웨어는 `userId`나 `postId`처럼 전달받은 자원별 파라미터 이름을 사용해야 합니다. 시작 코드는 검증과 404 전달을 건너뛰고 모든 오류를 500으로 처리합니다.

## 수정 파일과 fixture

- 수정: `src/errors.js`
- 정상·오류 ID: `fixtures/ids.json`

## 실행 진입점

`npm run check:10`

## 성공·실패 기준

정상 `userId`와 `postId`는 숫자로 변환되어 다음 미들웨어로 전달되고 잘못된 값은 400 커스텀 에러가 되면 성공합니다. 함수 내부에 특정 파라미터 이름을 고정하지 않고 전달받은 이름을 사용해야 합니다. JSON 파서처럼 `status` 또는 `statusCode`가 있는 4xx 오류는 상태 코드를 보존하면서 안전한 공통 본문으로 응답해야 합니다. 찾을 수 없는 경로는 404 커스텀 에러로 중앙 에러 핸들러에 전달하고, 알려지지 않은 오류만 내부 내용을 노출하지 않는 500 응답으로 처리해야 합니다. 중복 직접 응답, 잘못된 상태·본문, 내부 오류 노출은 실패합니다.
